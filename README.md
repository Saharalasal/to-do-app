# to-do app
this is a basic code for a to-do app. I programmed it as my first big project after my first year of university as a Computer Science student at Umm Al-Qura University. you can add, remove, change and print your tasks and it automatically puts a time stamp for each task! The application refreshes each time you perform a new Run.
# About the Project
The To-Do List Application is a task management program developed using Java. It allows users to maintain a list of tasks and perform essential operations to manage them efficiently iInstead of keeping track of tasks manually, users can manage their activities digitally by creating, updating, and removing tasks whenever needed.
# Project Objectives
* Develop a functional task management application using Java.
* Implement the fundamental CRUD operations: Create, Read, Update, and Delete.
* Practice writing clean, organized, and maintainable code.
* Apply programming concepts to a practical, real-world problem.
* Create a foundation that can be extended with more advanced features in the future.
# Features
* ➕ Add Tasks : Create new tasks and add them to your to-do list whenever you have something important to remember.
* ✏️ Edit Tasks : Modify existing tasks to correct information whenever your plans change.
* 🗑️ Delete Tasks : Remove tasks that are no longer needed and keep your list clean and organized.
* 📋 View Tasks : Display your existing tasks so you can easily review your activities.
* 🎯 Simple and Practical Design
# ⚙️ How It Works
The application follows a straightforward workflow:
1. Create a task: Enter the details of a task you want to remember.
2. View your tasks: Review the tasks currently available in your list.
3. Update a task: Edit a task whenever its information needs to change.
4. Delete a task: Remove an entry that is no longer necessary.
5. Keep your list organized: Continue managing your tasks as your daily plans evolve.
